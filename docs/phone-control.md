# Phone control via iOS Shortcuts

> When to read this: you want to start, stop, or check the OpenClaw
> container from your phone — no SSH, no Azure portal, no laptop.

## How it works

A dedicated **Service Principal** (SP) scoped to your single Container
Instance resource gets a token from Microsoft Entra ID, then the iOS
Shortcut hits the Azure REST API:

- `POST .../containerGroups/<name>/start`
- `POST .../containerGroups/<name>/stop`
- `GET  .../containerGroups/<name>?$expand=instanceView`

Three signed `.shortcut` files are generated by `scripts/gen-ios-shortcuts.py`,
ready to drop onto your iPhone via Files / iCloud Drive.

## 1. Create the Service Principal

```bash
source scripts/env.sh
SCOPE="/subscriptions/$SUBSCRIPTION/resourceGroups/$RG/providers/Microsoft.ContainerInstance/containerGroups/$CONTAINER"
az ad sp create-for-rbac \
  --name "openclaw-phone-control" \
  --role "Azure Container Instances Contributor Role" \
  --scopes "$SCOPE"
```

Output gives you `tenant`, `appId`, and `password`. Copy them into
`scripts/env.sh`:

```bash
export PHONE_CONTROL_TENANT_ID="<tenant>"
export PHONE_CONTROL_CLIENT_ID="<appId>"
export PHONE_CONTROL_CLIENT_SECRET="<password>"
```

The SP can do **only** start/stop/show on the one container — nothing
else in your Azure subscription is reachable with this credential.

## 2. Generate signed shortcuts

```bash
./scripts/gen-ios-shortcuts.py
```

This writes three files into `~/Downloads/openclaw-shortcuts/`:

- `OpenClaw-Status.shortcut`
- `OpenClaw-Start.shortcut`
- `OpenClaw-Stop.shortcut`

Each is signed with `shortcuts sign --mode people-who-know-me` so iOS
accepts it without a sketchy "Unsigned Shortcut" warning.

## 3. Install on iPhone

Easiest: drag the three `.shortcut` files into iCloud Drive on the Mac;
they sync to your iPhone within seconds. Tap each to import.

If iCloud sync stalls:

1. Delete any old versions on the iPhone first.
2. Drag-drop again on the Mac.
3. On iPhone: open Files app → iCloud Drive → tap the .shortcut → tap
   "Add Shortcut".

## 4. First run on iPhone

iOS prompts twice on first run of each shortcut:

1. **Allow Untrusted Shortcuts** — toggle it on under
   Settings → Shortcuts. (Hidden until you've run any shortcut once.)
2. **Per-domain network access** — Allow when prompted for
   `login.microsoftonline.com` and `management.azure.com`.

If you accidentally tapped Deny, reset under Settings → Shortcuts →
Advanced → Reset Privacy Settings.

## 5. Smoke test on Mac first

The same `.shortcut` files run on macOS via the `shortcuts` CLI:

```bash
shortcuts run "OpenClaw-Status"
# → "OpenClaw: Running"
```

Use this to confirm the SP credentials are right before debugging on
the phone.

## Common failure modes

| Symptom | Cause | Fix |
|---|---|---|
| "Unsigned shortcut" import error | Forgot `shortcuts sign` | Re-run `gen-ios-shortcuts.py` |
| `OpenClaw: <empty>` status | Action chaining missing | Already handled by current generator; if you customised, every action consuming previous output needs explicit `WFInput` |
| `400 invalid_client` from token endpoint | Wrong tenant or client ID | Re-check `PHONE_CONTROL_*` vars |
| `403 AuthorizationFailed` | SP scope wrong | Confirm SP scope is `containerGroups/$CONTAINER`, not just the RG |
| Shortcut works on Mac but not iPhone | iCloud sync stale | Delete on iPhone, drag-redrop on Mac |

## Alternative: Azure mobile app

If you don't want to deal with shortcuts, install the official **Azure
mobile app** (iOS / Android), sign in, find your container resource,
tap Start / Stop. Slightly slower but no setup.
